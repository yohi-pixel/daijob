# YesJob Debug 日志

## 2026-04-08 按公司筛选职位500错误

### 问题描述

按公司名称筛选职位时出现500错误：
```
SyntaxError: Unexpected token 'I', "Internal S"... is not valid JSON
```

### 根本原因

`JobSummary` 类（`backend/schemas/job.py`）缺少 `publish_time` 字段的日期验证器。

数据库中存在无效日期格式（如 `0000-00-00 00:00:00`），Pydantic 无法解析，导致 API 返回 HTML 格式的 500 错误页面，而非 JSON。

### 修复方案

在 `backend/schemas/job.py` 中添加 `_parse_datetime()` 函数：

```python
from datetime import datetime
from typing import Optional
from pydantic import BaseModel, field_validator

def _parse_datetime(v):
    """Parse datetime from string, return None for invalid dates."""
    if v is None:
        return None
    if isinstance(v, datetime):
        return v
    if isinstance(v, str):
        if not v or v in ('0000-00-00 00:00:00', '1970-01-01 00:00:00', ''):
            return None
        try:
            return datetime.strptime(v, '%Y-%m-%d %H:%M:%S')
        except Exception:
            return None
    return v

class JobSummary(BaseModel):
    # ... 字段定义 ...
    
    @field_validator('publish_time', mode='before')
    @classmethod
    def normalize_publish_time(cls, v):
        return _parse_datetime(v)
    
    model_config = {"from_attributes": True}
```
